# File illustrations

The ten illustrations in `public/file-icons/` use the **Bold flat** direction: colored paper silhouettes, white symbols and a folded corner. They were generated as one family with the built-in OpenAI image-generation tool, then cropped and downscaled into 128 × 152 transparent WebP assets (about 53 KB combined).

These are original generic file illustrations, not vendor logos. Filename extensions and file sizes remain selectable interface text, separate from the artwork. Icons are decorative and do not determine whether a file is safe to preview.

## Prompt

```text
Create a coherent family of exactly ten bold flat file icons in a five-column,
two-row grid. Every icon is a solid colored upright document silhouette with
gently rounded lower corners and a crisp folded upper-right corner. Large white
symbols, identical proportions, readable at 48px. No surrounding app tile, 3D
depth, drop shadows, texture, branding or watermark.

Order: red PDF with PDF lettering; blue document with horizontal lines; green
spreadsheet with a table grid; orange presentation with a slide/chart; teal
image with mountain and sun; pink audio with a musical note; purple video with
a play triangle; amber archive with a zipper; indigo code with </>; slate gray
generic file. Keep the folded corners and symbols opaque white. Transparent
background, generous spacing, no title or captions in the production sheet.
```
