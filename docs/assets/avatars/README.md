# Demo avatars

These six original fictional characters were generated with the built-in image-generation tool and resized to 256 × 256 through Agent Chat’s avatar uploader. They are demo personas, not product logos or claims of third-party integration. The Muse character is a separate official asset credited in `THIRD_PARTY_NOTICES.md`.
